Import from Excel

Update where items are, which phase they are in and their specs from an Excel file. Nothing is saved until you have seen every change and every problem, and pressed Apply.

  1. Get the sheet. Export the current items, or use a sheet you made the same way. Edit the yellow columns: Zone, Phase, Specs.
  2. Check it. Choose the file below. The page lists what would change and which rows have problems. Nothing is saved yet.
  3. Apply it. If it looks right, apply. Every change is added to the item's history with the file name.
Your account can look at the yard but not change it, so importing is switched off. Ask an administrator for editor access.
Drop an .xlsx file here or Excel Workbook (.xlsx), up to 2 MB. Older .xls and .csv files must be saved as .xlsx first.

What the columns mean
NameIdentifies the item. Do not change it. A name that is not in the system is reported as a problem; this page never creates items.
ZoneA zone code or name. An item that is still planned and gets a zone is placed on the yard. An item already on the yard is moved. Leave blank to keep it where it is.
PhaseA phase number from the item's own route. Only items on the yard can change phase. Leave blank to keep it.
SpecsA JSON object like {"Weight (t)": 92.5}. Write {} to clear all specs. Leave blank to keep them.
VersionLeave it alone. If someone changed the item after the sheet was exported, that row is refused instead of overwriting their work.
Other columnsHull, Level, Area, Parent, Status and the rest are for reading and are ignored on import.
