What the access levels mean
  • Viewer: can look at the map and the data, and export to Excel.
  • Editor: can also move items, change phases and specs, edit in the Data sheet and import from Excel.
  • Admin: can also use this page: manage people and add ships.
  • No access: can sign in but cannot see the yard. Disabling someone has the same effect and keeps their record.
  • From configuration: a role set on the server (the YARD_ADMINS style settings) is always kept. An administrator named there can never be locked out from this page.
